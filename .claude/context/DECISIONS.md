# Журнал решений

Формат: дата — решение — почему — последствия.

- **14.10 — Эталон = атрибуты YML-фида М.Видео (`skus.pkl`, `param`, `vendor`, `model`).** Отдельного gold-файла в архиве нет;
  каталожные атрибуты размечены контент-командой М.Видео — это «human-curated gold» по категориям. Вход модели — только текст из
  `sku_desc.parquet`, чтобы не было утечки. Дополнительно меряем, есть ли эталонное значение в тексте вообще («извлекаемый recall»).
- **14.10 — Трафик-веса из `query_clicks.parquet`.** Вес атрибута в категории = доля кликов по запросам, где упомянуто значение/имя атрибута.
  Это прямой ответ на метрику кейса «качество с учётом трафика».
- **14.10 — Перечень обязательных атрибутов вне смартфонов/ноутбуков выводим из данных** (заполненность в каталоге × спрос в запросах),
  для смартфонов и ноутбуков — ровно как в кейсе.
- **14.10 — Стоп-код планируем от 23.10**, а не 29.10 (29.10 — только финалисты).
- **14.10 — Фронтенд без сборки** (ES-модули + CSS, ассеты self-hosted): ревьюер должен запустить по README без npm; продукт работает в закрытом контуре.
- **14.10 — LLM по умолчанию `auto`**: включается, если задан ключ (`LLM_*` или `OPENAI_*` с ВМ). Локальный on-prem вариант — Ollama на GPU.
- **14.10 — Коммиты без соавторов** (CONTRIBUTING.md), push — в ветку + PR на GitHub; финальная сдача — `main` в Gitea.
- **14.10 — Параллельная работа агентов с владением файлами** (см. PLAN.md); коммитит только оркестратор.
- **14.10 — Метрики при неполном эталоне**: P/R/F1 только по парам (карточка, атрибут), где эталон есть; предсказания там,
  где каталог пуст, — `new_fills` (прирост покрытия), не FP. Отдельно `recall_extractable` (значение есть в тексте) — потолок.
- **14.10 — Мульти-эталон**: для модели/CPU/мультицвета допускается список корректных значений (совпадение с любым = TP).
- **14.10 — Holdout трогаем один раз** — финальный отчёт после интеграции правил, NER, классификатора категории и LLM.
- **15.10 — Локальная LLM: `qwen3:4b-instruct` через Ollama на Vulkan** (`ollama-attrx.service`, 127.0.0.1:11434).
  У CPU нет AVX → CPU-инференс непригоден; CUDA 13 не поддерживает GTX 1060; официальная CUDA-12 сборка медленнее (8,1 vs 6,9 с/карточка).
  qwen2.5:7b так же точна, но на 30% медленнее и +1,4 ГБ VRAM — рекомендация для выделенной GPU ≥ 8 ГБ. Клиент ходит на 127.0.0.1 (IPv6 зависал).
- **15.10 — Политика доверия к LLM (окончательно)**: значение, подтверждённое ТОЛЬКО LLM, никогда не принимается автоматически
  (status=review) — явное правило в pipeline.py + тест. LLM повышает уверенность, когда подтверждает продавца/правила/NER,
  и предзаполняет очередь модератора. Справочник допустимых значений — в промпте, не в JSON-enum (enum заставлял модель выбирать неверное).
- **15.10 — Классификатор категории: иерархия корень → лист, без pickle** (npz + vocab), коммитится (7,8 МБ), порог 0.9.
