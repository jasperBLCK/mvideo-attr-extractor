- Продуктовый хакатон = **«LLM-ревью репозитория»**: проверяется репозиторий команды в Gitea, берётся **последний коммит `main`** на момент запуска.
  Решение проверяется «по описанию и требованиям выбранного кейса» → README и структура репо должны явно показывать выполнение каждого требования.

- Если в репо только стартовый коммит — проверка пройдёт по пустому решению.

## Сдача и инфраструктура
- Работать на ВМ в `~/project` (клон репо команды), данные — `~/project/data`, ноутбуки — `notebooks/`, логи — `logs/`.
- Сдача: `git push origin main` в Gitea (только HTTP с паролем команды, SSH к Gitea нет). Памятка на ВМ: `~/README_SUBMIT.md`.
- Во время проверки push закрыт до её окончания; под стоп-кодом репо в архиве.
- На ВМ уже заданы **`OPENAI_API_KEY` и `OPENAI_BASE_URL`** (ключ LLM организаторов), пакет `openai` установлен. Лимит — дневной.
- **Демо должно слушать порт 8000** на ВМ («Демо» — публичный адрес машины). Жюри может открыть его во время питча.
- Карточка решения (заполняет капитан на «Сводке»): «Описание решения» до **8000 символов** + «Ссылка на решение» (по умолчанию сервер команды :8000).
  Под стоп-кодом поля только для чтения — заполнить заранее. Черновик: `docs/SOLUTION_CARD.md`.
- Правила: любые языки/фреймворки/открытые модели; **сторонний код — только с указанием источника в README**;
  нельзя передавать доступы к ВМ, использовать чужое решение, править код после стоп-кода.
- ВМ на 14.10 ещё не выдана («Организаторы ещё не создали ВМ»).
