## Как работать
- Локальный стенд: `systemctl --user start|restart attrx ollama-attrx` → http://127.0.0.1:8000 (после правок кода — restart attrx).
- Данные: `data/raw` (архив кейса), `data/processed` (готово, `attrx prepare` не нужен), NER-модель `models/ner` (локально, не в git).
- Машина: нет AVX (torch только на GPU, колёса cu126), Docker без root не работает, Ollama через Vulkan. См. память `machine-ml-runtime`.
- Hub gigaschool: публичные страницы — curl; вкладки — cookie Chromium (refresh_token ротируется → разлогинивает браузер).
- Коммиты без `Co-Authored-By`; язык доков/UI — русский; коммитить логическими группами.
