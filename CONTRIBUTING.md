# Как работаем вдвоём

- main всегда зелёный: ruff + pytest + attrx demo (то же гоняет CI).
- Задачи ведём в GitHub Issues по плану docs/PLAN.md, ветки feat/<что-делаем>, PR в main, ревьюит второй.
- Новое правило = новый тест в tests/ на реальный пример из датасета.
- Датасет, ключи и .env в git не коммитим (см. .gitignore). Ключи только в .env.
- Стоп-код для всех команд — **23.10** (зачётное LLM-ревью репозитория; 29.10 00:01 — только для финалистов). Финальный main пушим в Gitea на ВМ команды заранее, вечером 22.10: git remote add gitea <url>, затем git push gitea main.
- Соавторов в коммиты не добавляем, каждый коммитит от своего аккаунта.
