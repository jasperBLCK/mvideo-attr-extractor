# Внедрение в М.Видео без VPN и прокси

1. **Режим «только правила»** — нет внешних вызовов, один Docker-контейнер, батч или API.
2. **On-prem LLM** — vLLM или Ollama с открытой моделью (Qwen2.5-7B/14B-Instruct) на GPU-сервере в контуре. Меняются только LLM_BASE_URL и LLM_MODEL. Данные не выходят за периметр.
3. **Российские облачные LLM** — GigaChat, YandexGPT: доступны из РФ без VPN, OpenAI-совместимые. Наружу уходит только текст карточки, без персональных данных.

Масштаб: правила обрабатывают тысячи карточек в секунду на CPU. LLM зовётся только для хвоста, и это управляется порогом LLM_ROUTE_THRESHOLD и лимитом LLM_MAX_CALLS. Кэш исключает повторную оплату.

Интеграция: POST /api/extract/batch из PIM/контент-системы, либо attrx extract по выгрузке. Результат со статусом review идёт в существующий интерфейс модерации или в наш UI.
