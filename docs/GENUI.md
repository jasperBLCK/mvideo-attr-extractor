# Generative UI

Идея как в Agentic OS: интерфейс не свёрстан заранее под один сценарий, а собирается под задачу.
В проде М.Видео нельзя выполнять произвольный HTML/JS от модели, поэтому сделали так:

1. Бэкенд извлекает характеристики (ExtractionResult).
2. LLM получает только метаданные (ключи атрибутов, статусы, уверенность) и запрос пользователя и возвращает **UISpec**: заголовок, раскладку и список компонентов из словаря: summary, alert, attribute_table, confidence_chart, evidence, review_queue, metrics.
3. UISpec валидируется pydantic-схемой (src/attrx/genui/schema.py): неизвестный компонент или лишнее поле приводят к откату на шаблон. Ключи атрибутов фильтруются, разметка в тексте экранируется.
4. Фронтенд (web/components.js) рендерит компоненты, а **значения берёт из result, не из ответа LLM**. Поэтому модель не может показать характеристику, которой нет.
5. Без LLM работает детерминированный шаблон compose_default.

Как добавить компонент: тип в ComponentType и JSON-схему, функцию в registry (web/components.js), упоминание в SYSTEM-промпте композитора, тест.
