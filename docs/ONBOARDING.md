# attrx — коротко о кейсе и как всё запустить

Шпаргалка на 5 минут для команды перед продуктовым чекпоинтом 15.10 (19:00–19:10, «Зал 1»).
Та же структура, что в онбординг-деке. Все цифры — из `submission/` (отчёт v2 на holdout).

## 1. Кейс за минуту

- **Задача (кейс № 3, М.Видео):** из текста карточки товара (название, описание, поля продавца) автоматически заполнить
  характеристики: бренд, модель, память, диагональ, цвет… У каждого значения — **уверенность** от 0 до 1.
- **Условия:** надёжное сразу идёт в каталог, сомнительное — человеку. Выдумывать нельзя. На входе только текст, без картинок.
- **Зачем:** поле заполнено → товар виден в фильтрах и поиске → клики и покупки → растёт **GMV** (оборот, сумма продаж).
  56,5 % поисковых кликов — по запросам с характеристикой («телевизоры 55», «посудомоечная машина 45 см»).
- **Пример (реальная карточка):** «Восстановленный смартфон Xiaomi Redmi Note 10 Pro 8/256Gb Glacier Blue, хороший» →
  бренд Xiaomi 1,00 · модель Redmi Note 10 Pro 1,00 · память 256 ГБ 1,00 · цвет синий 0,98 · диагональ — нет в тексте.

## 3. Что мы построили

```
текст карточки → категория → правила и словари → NER → LLM (только остаток)
   → проверка цитаты → уверенность → статус: принято / на проверку / нет в тексте
   → UI модератора → правки пополняют словари (система учится)
```

- **Категория** — из каталога, а если её нет, классификатор по тексту (точность 0,9998).
- **Правила и словари** — ядро: 4 822 бренда, единицы, цвета; меньше 1 мс на карточку.
- **NER** (распознавание сущностей: нейросеть размечает слова в тексте) — ловит значения в свободных фразах.
- **LLM** зовём только для полей, где пусто, слабо или конфликт (31 % карточек). Значение без цитаты из текста выбрасывается.
  Значение, которое нашла только LLM, **никогда не идёт в каталог само** — только человеку.
- **Статус:** «принято» — сразу в каталог; «на проверку» — модератору; «нет в тексте» — поле остаётся пустым.

## 4. Пять цифр, которые надо помнить

| Цифра | Что значит простыми словами |
|---|---|
| **0,954** | точность принятого: из 1 000 значений, которые система сама записала в каталог, 954 совпали с каталогом М.Видео (цель ≥ 0,95) |
| **0,858** | F1 (одна оценка из точности и полноты) на 23 391 карточке holdout — отложенных, которые не трогали при настройке |
| **80,7 % → 88,1 %** | заполненность каталога: доля обязательных полей со значением до и после (+5 488 значений) |
| **38 %** | столько значений, найденных только LLM, верны → такие значения всегда идут человеку на проверку |
| **в 4–7 раз** | гибрид дешевле, чем «LLM на каждую карточку»: 0,83 ₽ против 5,6 ₽ за 1 000 карточек на своей GPU |

## 5. Порог: 0,70 и строгий режим 0,82

- **Уверенность** — число от 0 до 1: насколько система уверена, что значение верно. **Порог** — черта:
  выше — значение сразу пишем в каталог, ниже — отдаём человеку.
- **0,70 — сейчас, в сдаче:** точность принятого 0,954 (цель ≥ 0,95), система сама принимает 94 % найденного.
- **0,82 — «строгий режим»:** точность 0,982, но сама принимает 85,5 % — больше ручной проверки. Подобран на dev,
  на holdout не проверен.
- **Зачем вообще думать о 0,82:** значения с уверенностью 0,70–0,80 верны лишь в 57 % случаев (4 % принятого,
  в основном цвет и модель). Порог выбирали только на dev (карточки для настройки), подгонять его под holdout нельзя.
  Итог: в сдаче 0,70, строгий режим описан в доках, а где его включать, решаем по категориям в пилоте.

## 6. Как запустить

**Стенд уже запущен** на этой машине: http://127.0.0.1:8000

```bash
systemctl --user start attrx ollama-attrx      # если стенд не отвечает
systemctl --user restart attrx ollama-attrx    # после правок кода
```

**С нуля (5 минут, датасет не нужен; нужны Python 3.11 и uv):**

```bash
uv venv -p 3.11 .venv && uv pip install -p .venv/bin/python -e ".[dev]"
.venv/bin/attrx demo     # прогон на 400 реальных карточках + метрики
.venv/bin/attrx serve    # http://127.0.0.1:8000
```

**Docker:** `docker compose up --build`. На этой машине Docker работает только через sudo, и он занимает тот же
порт 8000, что и стенд:

```bash
systemctl --user stop attrx
sudo docker compose up --build    # http://localhost:8000
```

Без LLM работает всё: правила, словари, классификатор, NER.

## 7. Что показать в демо

1. **Карточка** — наведи мышь на значение в таблице, и в тексте слева подсветится цитата, откуда оно взято
   («Своя карточка» — вставить любой текст).
2. **Очередь проверки** — сомнительные значения по очереди: `A` — принять, `E` — исправить, `R` — отклонить.
3. **Качество** — метрики holdout и что даёт каждый шаг: правила → продавец → NER.
4. **Ctrl+K** → «покажи только конфликты»: экран соберётся под запрос из готовых блоков (generative UI).

Скриншоты: `docs/img/ui_workbench_light.png`, `ui_review_light.png`, `ui_quality_light.png`.

## 8. Что сказать на чекпоинте

Слайды — `docs/checkpoint/concept.pdf`, речь и 15 ответов — `docs/checkpoint/SPEECH.md`.
Говорят: Makhkets — продукт и внедрение, jasperBLCK — пайплайн и цифры.

**Речь, 5 минут:**
1. **Проблема.** Пустое поле → товара нет в фильтре → теряем GMV.
2. **Решение.** Правила — ядро, NER и LLM — для остатка; у каждого значения цитата и уверенность.
3. **Доверие.** Одна LLM в каталог не пишет: права лишь в 38 % случаев; 61 ответ без опоры в тексте отброшен.
4. **Цифры.** Точность принятого 0,954 · F1 0,858 на 23 391 карточке · каталог 80,7 → 88,1 %.
5. **Внедрение.** Тень 2–4 недели (работает рядом, в каталог не пишет) → автопринятие в топ-категориях; в 4–7 раз дешевле.

**Топ-6 вопросов:**
- *Как не даёте LLM выдумывать?* Цитата обязательна и сверяется с текстом; значение только от LLM всегда идёт человеку.
- *Сколько стоит?* 0,83 ₽ за 1 000 карточек на своей GPU, в 4–7 раз дешевле «LLM на каждую»; без LLM — меньше копейки.
- *Новая категория?* Её определит классификатор по тексту (0,9998); новая категория — файл настроек (YAML), без кода.
- *Мелкие продавцы не пострадают?* F1 маркетплейса 0,853 против 0,873 у М.Видео — разрыв 2 п.п. при цели ≤ 5.
- *LLM не добавила к F1 — зачем она?* Подсказки модератору и помощь на новых категориях; в каталог одна она не пишет.
- *Как встроить, не утекут ли данные?* REST API или CLI к PIM (система каталога); LLM ставится внутри контура М.Видео.
