# Структура презентации

1. Проблема: ручное заполнение характеристик — медленно, дорого, ошибки бьют по фильтрам и поиску.
2. Решение одной фразой и демо-скрин UI.
3. Архитектура гибрида: правила → LLM на хвост → проверка → уверенность → модератор.
4. Анти-галлюцинации: цитата и заземление, пример отброшенного значения.
5. Generative UI: один и тот же результат, разные запросы, разные экраны.
6. EDA: что в данных, пропуски, распределения.
7. Метрики: P/R/F1 по атрибутам, coverage, traffic-weighted, по категориям; правила vs правила+LLM.
8. Порог уверенности: кривая precision/coverage, выбранная рабочая точка.
9. Внедрение без VPN: on-prem или российские LLM, Docker, API.
10. Риски и экономика: доля карточек без ручного труда, стоимость на 1000 карточек.
11. Что дальше.
