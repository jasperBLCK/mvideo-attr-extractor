# Риски и как закрываем

| Риск | Мера |
|---|---|
| Галлюцинации LLM | Обязательная цитата и проверка заземления, справочники допустимых значений, статус review |
| Стоимость | LLM только для хвоста, кэш, лимит вызовов, локальная модель |
| Длинный хвост категорий | Фолбэк generic, неуверенная категория уходит на проверку, таксономия в YAML, добавление категории без кода |
| Новые категории (cold start) | LLM предлагает значения со статусом review, правки модераторов пополняют словари |
| Неравенство продавцов | Не штрафуем бедные карточки: заполняем из текста; продавец не главный источник (0.8), конфликт продавца и текста уходит на проверку |
| Переобучение на sample | Holdout из gold, правила тюним только на train |
| Недоступность провайдера | Фолбэк на правила, смена провайдера одной переменной |
