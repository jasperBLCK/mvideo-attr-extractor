# web/ — консоль модератора attrx

Интерфейс без сборки: обычные ES-модули и CSS, их отдаёт FastAPI (`attrx serve` → http://localhost:8000).
npm не нужен, шрифты и иконки лежат в `assets/` (источники и лицензии: [assets/CREDITS.md](assets/CREDITS.md)).

## Разделы

| Раздел | Адрес | Что делает |
|---|---|---|
| Карточка | `#/card?id=<id>` | слева текст карточки, справа характеристики. Наведение на характеристику подсвечивает цитату в тексте, и наоборот. Значение, уверенность со шкалой порога, статус, источники, альтернативы, решение модератора |
| Очередь проверки | `#/review` | значения ниже порога и конфликты; порядок — вес в поиске × (1 − уверенность). Клавиши J/K, A, E, R, U, 1–9 |
| Качество | `#/quality` | всё из `submission/*.json`: сравнение подходов, порог, калибровка, атрибуты, сегменты, категории, спрос, стоимость, ошибки. Нет файла — честное «ещё не посчитано» |
| Палитра | Ctrl/⌘ K | собрать экран под запрос (generative UI), найти карточку, перейти, сменить тему |
| Справка | `?` | статусы, источники, уверенность, цитаты, клавиши |

## Файлы

~~~

## Дизайн-токены

Метафора — стол корректора: карточка лежит листом (`--sheet`) на сером столе (`--paper`), текст продавца набран
книжной Literata (`--font-doc`), интерфейс — Onest (`--font-ui`). Красная ручка `--pen` (фирменный красный М.Видео
`#E2231A`) отмечает только то, что требует решения: активную цитату, засечку порога, рабочую точку на графике,
главное действие, текущий раздел.

| Группа | Токены |
|---|---|
| Поверхности | `--paper`, `--sheet`, `--raised`, `--field`, `--hover`, `--selected` |
| Текст | `--ink` → `--ink-4` (четыре уровня, `--ink-4` только для неактивного) |
| Линии | `--rule`, `--rule-2`, `--rule-3` |
| Акцент | `--pen`, `--pen-strong` (красный текст), `--pen-wash` |
| Цитаты | `--mark`, `--mark-line`, `--mark-active` |
| Статусы | `--accepted`, `--review`, `--review-fill`, `--missing` (+ `-wash`); всегда с иконкой и подписью |
| Графики | `--series-1` (точность), `--series-2` (покрытие), `--heat-0…4`, `--grid`, `--axis` |
| Шаги и радиусы | `--s-1…16` (шаг 4 px), `--r-xs 4`, `--r-sm 6`, `--r-md 8`, `--r-lg 12` |
| Движение | `--ease-out`, `--dur-1…3`; частые действия (клавиши, палитра) без анимации |

Контраст текста проверен для обеих тем (WCAG AA), палитра графиков — валидатором различимости при дальтонизме.

## Как добавить компонент generative UI

1. Тип в `ComponentType` и описание в `COMPONENTS` — `src/attrx/genui/schema.py` (описание попадёт в промпт LLM).
2. При необходимости ключевые слова в `_INTENTS` — `src/attrx/genui/composer.py` (сборка экрана без LLM).
3. Функция `registry.<тип>(c, result, ctx)` в `components.js`: данные брать только из `result`, текст выводить через
   `h()` (без innerHTML), вернуть элемент `blk(...)`.
4. Стили в `styles.css` (раздел «компоненты экрана»), только токены из `tokens.css`.
5. Тест в `tests/test_api_ui.py` и строка в `docs/GENUI.md`.
